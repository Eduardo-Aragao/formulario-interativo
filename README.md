Projeto desenvolvido como parte do Desafio de Avaliação Prática 3 da graduação em Engenharia de Software. O objetivo foi criar uma interface de formulário robusta, focando em interatividade em tempo real e validação de dados via JavaScript.

## 🎯 Desafio Proposto
O projeto deveria contemplar obrigatoriamente:
- **Campos:** Nome completo e E-mail.
- **Interatividade:** Validação dinâmica com JavaScript.
- **Feedback:** Mensagens de erro contextuais e resposta visual ao usuário (UX).

## 🧠 Conceitos Aplicados
Para a resolução deste desafio, apliquei os seguintes conceitos técnicos:
- **Manipulação de DOM:** Acesso e alteração dinâmica de elementos HTML.
- **Eventos JS:** Escuta de submissão e input para validação instantânea.
- **Lógica de Condicionais:** Verificação de campos vazios e formatos de e-mail.
- **UX & Feedback Visual:** Alteração de cores e estados para guiar o usuário.
- **Acessibilidade & ES6+:** Código limpo e uso de constantes/arrow functions.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica.
- **CSS3:** Layout responsivo e estilização de estados (erro/sucesso).
- **JavaScript (Vanilla):** Lógica de validação e controle do formulário.
